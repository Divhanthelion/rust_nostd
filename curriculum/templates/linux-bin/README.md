# {{name}}

A freestanding Linux executable generated by `nostd new linux-bin`:
`#![no_std]`, `#![no_main]`, no libc, no crt0, a few kilobytes in release mode.

```sh
cargo build --release
echo "shout this" | ./target/release/{{name}} a b c
ls -l target/release/{{name}}          # tiny
file target/release/{{name}}           # "statically linked"
```

How it fits together:

* `rt/` is the runtime crate (the same `nostd_rt` you study in the course):
  `_start` in `global_asm!`, raw syscalls, argv/envp, `print!` macros, and
  the `memcpy`/`memset`/`memcmp`/`bcmp`/`memmove`/`strlen` symbols the
  compiler expects. It is marked `#![no_builtins]`.
* `build.rs` passes `-nostartfiles -static -no-pie` to the linker for the
  binary only.
* `Cargo.toml` sets `panic = "abort"`; `src/main.rs` defines the panic handler.

Linux on x86_64 and aarch64 only. On other hosts, build inside a Linux
container or VM.
