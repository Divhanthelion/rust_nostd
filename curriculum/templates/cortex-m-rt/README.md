# {{name}}

Cortex-M3 firmware on the standard rust-embedded stack, generated by
`nostd new cortex-m-rt`:

| crate                  | role                                                     |
|------------------------|----------------------------------------------------------|
| `cortex-m-rt`          | vector table, Reset handler, `#[entry]`, `#[exception]`  |
| `cortex-m`             | core peripherals (SysTick, NVIC, SCB), `asm::wfi`, critical sections |
| `cortex-m-semihosting` | `hprintln!`, `debug::exit` through the debugger/QEMU     |
| `panic-semihosting`    | the `#[panic_handler]`                                   |

```sh
rustup target add thumbv7m-none-eabi
cargo run              # needs network access once to fetch the crates
```

Next steps on real hardware: add your chip's PAC/HAL (e.g. `stm32f4xx-hal`,
`embassy-stm32`), replace semihosting with `defmt` + `defmt-rtt`, swap
`panic-semihosting` for `panic-probe`, and flash with `probe-rs run --chip <CHIP>`.
