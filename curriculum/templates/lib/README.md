# {{name}}

A portable `#![no_std]` library, generated by `nostd new lib`.

```sh
cargo test --all-features                        # host tests
cargo build --target thumbv7em-none-eabihf       # prove it builds without std
cargo clippy --all-features                      # safety-oriented lints (see Cargo.toml)
```

Layout of the feature flags:

| feature | enables                                   | final binary must provide |
|---------|-------------------------------------------|---------------------------|
| (none)  | everything that only needs `core`         | a `#[panic_handler]`      |
| `alloc` | heap-backed helpers (`to_hex`)            | a `#[global_allocator]`   |
| `std`   | std integrations; implies `alloc`         | an operating system       |

Rules of thumb:

* the crate is *always* `#![no_std]`; `std` is opt-in via `extern crate std`;
* depend on other crates with `default-features = false` and forward features;
* never define `#[panic_handler]` or `#[global_allocator]` in a library.
