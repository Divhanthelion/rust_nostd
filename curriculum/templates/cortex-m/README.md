# {{name}}

Cortex-M3 firmware with **zero dependencies**, generated by `nostd new cortex-m`.
Everything that `cortex-m-rt` normally hides is in plain sight:

* `link.x`: memory map, sections, vector table placement, `.data`/`.bss` symbols
* `src/main.rs`: vector table, reset handler, SysTick exception, semihosting, panic handler
* `.cargo/config.toml`: default target + QEMU runner
* `build.rs`: hands the linker script to the linker

```sh
rustup target add thumbv7m-none-eabi
cargo run                     # boots in QEMU (apt install qemu-system-arm / brew install qemu)
cargo size --release          # with cargo-binutils: how big is the firmware?
```

Expected output:

```text
booted: .data says 0xc0ffee
handled 10 SysTick interrupts
```

Porting to real hardware: change `MEMORY` in `link.x`, extend the vector table
with your MCU's interrupts (from its reference manual), remove semihosting
(it faults without a debugger attached) and flash with `probe-rs run`.
